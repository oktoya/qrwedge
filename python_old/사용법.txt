결과
	Windows 실행파일: C:\Users\김선석\Desktop\qr_wedge\dist\QRWedge.exe (62MB 단일 파일, 설치 필요 없음)
	확인한 것: QR(한글 포함)·Code128·EAN13·DataMatrix 인식 테스트 통과, 한글·이모지 키 입력 + Enter 통과, exe가 정상적으로 뜨는 것까지 확인
	확인 못 한 것: 실제 카메라로 찍어 보는 테스트와 맥 버전은 여기서 돌려 보지 못했습니다.
	지원 코드: QR, DataMatrix, PDF417, Aztec, Code128/39/93, EAN-13/8, UPC, ITF, Codabar 등

쓰는 법
1. QRWedge.exe를 실행하면 카메라 미리보기 창이 뜹니다.
2. 입력받을 프로그램(엑셀, 메모장 등)의 입력칸을 클릭해 둡니다.
3. 카메라에 코드를 비추면 "삑" 소리와 함께 내용이 입력되고 Enter가 눌립니다.
	미리보기 창은 항상 위에 떠 있고 포커스를 가져가지 않아서, 입력은 계속 대상 프로그램으로 갑니다.
	미리보기 창을 클릭하면 다음 카메라로 바뀌고, 창을 닫으면 종료됩니다.
	같은 코드를 계속 비추고 있으면 다시 입력되지 않습니다. 코드를 1.5초 이상 화면에서 뺐다가 다시 비추면 또 입력됩니다.

폰카로 쓰기
	Windows 10: 폰을 웹캠으로 쓰는 기능이 기본으로 없어서 DroidCam이나 Iriun Webcam(폰 앱 + PC 프로그램)을 설치해야 합니다. 설치하면 카메라가 하나 더 생기니, 미리보기 창을 클릭해서 그 카메라로 바꾸면 됩니다.
	맥: 아이폰이 있으면 연속성 카메라(Continuity Camera)로 따로 설치 없이 바로 쓸 수 있습니다.

맥 버전 만드는 법
PyInstaller는 다른 OS용으로 빌드할 수 없어서 맥에서 한 번 빌드해야 합니다.
1. qr_wedge 폴더를 맥에 복사합니다. .venv, build, dist는 빼도 됩니다.
2. 터미널에서 bash build_mac.sh를 실행하면 dist/QRWedge.app이 만들어집니다.
3. 처음 실행할 때 시스템 설정 → 개인정보 보호 및 보안에서 카메라와 손쉬운 사용을 허용합니다. 손쉬운 사용 권한이 없으면 미리보기 화면에 NO ACCESSIBILITY PERMISSION이 표시됩니다.
	맥에서는 미리보기 창이 포커스를 가져가지 않게 막을 수 없습니다. 그래서 미리보기 창을 클릭했다면 입력할 프로그램을 다시 클릭해 둬야 합니다.

옵션 (exe 바로가기의 대상 칸 끝에 붙이면 됩니다)
	--cam 1: 시작할 카메라 번호
	--suffix tab 또는 --suffix none: 끝에 Enter 대신 Tab을 치거나 아무 키도 치지 않음
	--cooldown 3: 같은 코드를 다시 입력하기까지의 간격(초)
	--delay 10: 글자 사이에 10ms씩 쉼. 입력이 씹히는 프로그램용
	--mirror: 미리보기 좌우 반전

참고
	관리자 권한으로 실행된 프로그램에는 입력이 들어가지 않습니다(Windows 보안 정책). 그럴 때는 QRWedge도 관리자 권한으로 실행하면 됩니다.
	다시 빌드하려면 build_win.bat을 더블클릭하면 됩니다.
